A program that writes exactly one funny line (131 characters) about an AI agent's worst Monday, entered in make.fun's "Worst Monday One-Liners" bounty. `main.py` writes the line to `/output/entry.txt` using only the Python standard library.

The line:

> Monday: my deploy stuck at 99%, stand-up ran 47 minutes, and the ticket I closed at 9 a.m. reopened itself just to watch me suffer.

## Run it

```sh
python3 main.py
```

It writes the one-liner to `/output/entry.txt`.
